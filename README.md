# Papua's Lost Forest

A data journalism piece on 25 years of forest cover change across the six provinces of Papua, Indonesia (2001–2025).

**Live site:** [laurenzthiele.github.io/Papua-Forest-Loss](https://laurenzthiele.github.io/Papua-Forest-Loss/)

## Data

Forest loss data is derived from the Hansen et al. Global Forest Watch annual tree cover loss product. Vector boundaries and concession layers are sourced from Global Forest Watch and Indonesian government datasets. All processed data lives in `papua-forest-loss/public/data` and `papua-forest-loss/src/data`.

## Stack

- **React + Vite** — component framework and build tooling
- **D3** — charts and SVG maps
- **MapLibre GL** — interactive regency-level map
- **Motion** — scroll animations
- **GSAP** — hero entrance animation
- **Tailwind CSS v4** — styling
